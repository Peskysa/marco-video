# Contribuir

Consulta [Desarrollo](docs/DESARROLLO.md). Las contribuciones originales se ofrecen bajo AGPL-3.0-only; las dependencias conservan sus licencias. Ejecuta las pruebas funcionales y `python scripts/distribution.py check`. Mantén las cinco modalidades, los avisos de terceros, las capturas reales y la accesibilidad. Nunca incluyas claves de firma, credenciales ni documentos personales.
