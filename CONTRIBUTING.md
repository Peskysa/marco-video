# Contribuir

Describe el problema, sistema y versión, formato/códec y pasos para reproducirlo. Utiliza vídeos de prueba que puedas compartir y evita datos personales. Aporta cambios pequeños con pruebas de comportamiento y actualiza las tres traducciones y el manual si cambia la interfaz. No subas claves, credenciales, películas ni medios sin autorización.

Consulta [Desarrollo](docs/DESARROLLO.md). Las contribuciones se ofrecen bajo GPL-3.0-only; las dependencias conservan sus licencias.
