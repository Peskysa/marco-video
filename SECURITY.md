# Seguridad

No adjuntes vídeos personales ni secretos en incidencias. Para un problema sensible utiliza la función de informe privado de vulnerabilidad de GitHub si está habilitada, o contacta con el propietario por un canal privado ya acordado. No se inventa una dirección de contacto.

El reproductor procesa archivos potencialmente complejos con motores de terceros: conserva actualizados Qt, FFmpeg, navegador y WebView. No ejecuta código de subtítulos ni permite esquemas de URL como `javascript:`. Las URL y archivos elegidos se abren por acción del usuario.

No se incluyen credenciales, claves de firma ni servidores de subida. Los ejecutables de Windows no tienen firma comercial. Una suma SHA-256 comprueba integridad y no demuestra por sí sola la confianza en el origen.
