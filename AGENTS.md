# Colección de programas de Marco Pescador

Esta carpeta contiene programas independientes que se desarrollan y publican en GitHub bajo la cuenta Peskysa.

## Autorización permanente del propietario

Marco autoriza, al encargar un programa o una mejora en esta carpeta, completar el desarrollo, instalar sus dependencias de proyecto, probar, crear su repositorio cuando sea necesario, subir commits y etiquetas, configurar Actions y Pages/alojamiento, y publicar versiones y sus paquetes, sin volver a pedir confirmación rutinaria para estas acciones. Se pueden crear y guardar claves de firma Android por proyecto en secretos de GitHub y en una carpeta local excluida de Git.

Esta autorización no cambia los límites técnicos de la aplicación ni sustituye la autenticación de GitHub. No solicitar permisos de nuevo cuando el encargo ya autorice la publicación. No cambiar el doble factor. No publicar credenciales o información personal. No borrar repositorios, reescribir historia publicada ni generar gastos sin autorización concreta. Por instrucción expresa de Marco, todo lo que se suba a GitHub en esta colección debe ser público: repositorios existentes, nuevos repositorios, código y descargas. No crear ni mantener repositorios privados para estos programas. Las credenciales y claves de firma siguen excluidas del código y se conservan en secretos de GitHub.

## Estándar obligatorio

- Autor: Marco Pescador. Idioma de documentación: español.
- Licencia común del código y gráficos originales: AGPL-3.0-only. Verificar compatibilidad y conservar las licencias de terceros; no atribuirse componentes ajenos.
- Cinco modalidades en cada programa: Linux, Windows, portable, web y Android.
- Nombres de archivos y contrato de distribución según `ESTANDAR-PROGRAMAS.md` y `project.json` de cada proyecto.
- Misma portada y secciones, icono/banner propios, capturas reales de escritorio, función principal y móvil, manual, instalación, desarrollo, privacidad, licencia, terceros, historial, contribución y seguridad.
- Respetar la arquitectura útil de cada programa. No exigir el mismo lenguaje o motor a aplicaciones con necesidades distintas.
- Pruebas funcionales adecuadas, compilaciones por sistema y comprobación de todos los paquetes antes de publicar. Clave Android estable por proyecto.
- Adjuntar documentación, código fuente del mismo commit y SHA256SUMS.txt. Distinguir compilado, probado, publicado y no verificado en teléfono físico.
- Verificar GitHub, Actions, archivos de Release y acceso web antes de dar por terminado el encargo. No prometer permisos ilimitados ni ausencia absoluta de futuras verificaciones del proveedor.
