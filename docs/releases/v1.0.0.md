# Marco Vídeo 1.0 · ES / EN / FR

Nuevo reproductor independiente para archivos de vídeo y audio propios, con listas, SRT/VTT, velocidad, A–B, marcadores, reanudación, capturas y temporizador.

| Variante | Descarga |
| --- | --- |
| Portable Windows x64 | `Marco-Video-Portable.exe` |
| Portable web sin Internet, Windows x64 | `Marco-Video-Web-Portable.exe` |
| Web normal o carpeta sin Internet | `Marco-Video-Web.zip` |
| Instalador Windows x64, por usuario | `Marco-Video-Windows-Instalador.exe` |
| Instalador Linux amd64 | `Marco-Video-Linux-amd64.deb` |
| APK Android firmado | `Marco-Video-Android.apk` |

También: portable Linux en carpeta, documentación, código fuente del proyecto y SHA-256. El ZIP web permite abrir `index.html` sin Internet; para una dirección alojada se necesita conexión. El portable web Windows incorpora un servidor solo local y abre el navegador.

Qt/FFmpeg en escritorio ofrece compatibilidad adicional frente a navegador/WebView. Los códecs dependen de la plataforma; no se garantizan todos los formatos. No incluye DRM, servicios de plataformas ni conversión. APK compilado y firmado, pendiente de prueba en teléfono físico.

Interfaz español, inglés y francés. Sin analítica ni subida de vídeos locales. GPL-3.0-only para el código original, dependencias con sus licencias propias.
