# Marco Vídeo 1.1.0

18 de octubre de 2026. Unificación de la colección Marco Pescador.

- Misma estructura de portada, documentación, capturas auténticas y licencia AGPL-3.0-only para el código original.
- Cinco modalidades: Linux, Windows, portable, web y Android. APK de publicación con clave propia estable.
- Instalador Windows, portable Windows, web portable, DEB Linux, portable Linux, ZIP web, documentación y fuente correspondiente.
- Comprobación obligatoria de todos los paquetes y sumas SHA-256 antes de publicar.

Los formatos reproducibles dependen de los códecs de cada plataforma. Web y Android tienen menos formatos que escritorio. Sin DRM, conversión ni descarga de plataformas. El APK no se ha probado en un teléfono físico. Los ejecutables Windows no tienen firma comercial. Los terceros conservan sus licencias y las ediciones anteriores sus condiciones originales.
